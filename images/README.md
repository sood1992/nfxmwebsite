# Images Directory

This directory will contain all website images and media files.

## Note
Images are currently not included in the repository due to size constraints.

Please upload your images using one of these methods:

1. **Via Visual Editor:**
   - Access https://yourdomain.com/editor/
   - Click the Media tab
   - Upload your images

2. **Via FTP:**
   - Connect to your server
   - Upload to /public_html/images/

3. **Via cPanel File Manager:**
   - Navigate to /public_html/images/
   - Upload your files

## Supported Formats
- JPG/JPEG
- PNG
- GIF
- WebP
- SVG
- MP4 (videos)
- WebM (videos)
- OGG (videos)
